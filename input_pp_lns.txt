# Rescattering weights. The one ep -> e'p p pbar final state holds BOTH
# rescattering subsystems, so every event gets two weights,
#   w_pbarp = sigma_pbarp(s_rpbar, t) / D_gen(s_rpbar, t)
#   w_pp    = sigma_pp   (s_rp,    t) / D_gen(s_rp,    t)
# An event rescatters EITHER pbar-p OR p-p, so the hypotheses add. A
# FOURTH accept-reject keeps the event with probability
#   ratio_weight_hypothesis: both  -> (w_pbarp + w_pp) / w_max  untagged mixture
#   ratio_weight_hypothesis: pbarp -> w_pbarp / w_max           pbar-p class only
#   ratio_weight_hypothesis: pp    -> w_pp / w_max              p-p class only
# To extract dsigma/dt|s_rpbar over dsigma/dt|s_pp by counting, run once
# with pbarp and once with pp and cat the LUND files: each half binned in
# its own s follows its own sigma. The untagged `both` mixture cannot be
# split back into classes.
#
# ratio_weight_proposals: N stops after N proposals reach this stage
# (num_events is then ignored). With the SAME N and the SAME
# ratio_weight_max in both runs, each file keeps its physical yield and
# the ratio is a plain count ratio in the cat'ed file. Single-class runs
# write their class (1 pbar-p, 2 p-p) in the LUND header's 9th column.
#
# Each model is a TFormula in s and t, or a TH2D table from
# reweight/build_dsdt_table.py (prefer --log + ratio_weight_mode: log).
# D_gen is the generated (s, t) density from an unweighted run
# (build_dsdt_table.py --from-gen); optional, and what makes each factor
# reproduce its sigma rather than sigma x D_gen.
#
# ratio_weight_max is the accept-reject ceiling on the accepted weight:
# any number at or above its max, a plain constant included (for the
# formulas below: e^3 ~ 20.1 for pbarp, e^1 ~ 2.7 for pp). Too
# high only costs efficiency. Omit it and the ceiling is scanned off the
# tables and the D_gen grid at load time -- but a formula model with
# neither has no grid to scan, so there it is required. Events whose
# weight exceeds the ceiling are clamped and counted in the run summary.
#
# ratio_weight_apply: carry turns the selection off instead: every event
# kept, both weights carried (truth branches w_pbarp, w_pp, w_ratio,
# w_event; optional two-column sidecar).
ratio_weight_formula:     exp(3.0 + (4.0 - 1.0*log(s/3.52))*t)
ratio_weight_formula_den: exp(1.0 + (2.0 + 0.5*log(s/3.52))*t)
