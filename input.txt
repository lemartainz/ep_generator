# 3-D cross-section weight w(Q2, W, M_X), built by
# reweight/build_xsec_weight3d.py. M_X is the invariant mass of the
# intermediate from the first vertex -- M_ppbar for the reaction above.
# Applied as a SECOND accept-reject, after the decay chain, since M_X does
# not exist at electron-sampling time.
#   Format:  xsec_weight: <root file> [<hist name>]   (default w_Q2_W_M)
#            xsec_weight_mode: interp | bin           (default interp)
# `interp` trilinearly interpolates between bin centers -- a continuous
# w(Q2, W, M), the right pairing for a smooth cross section. `bin` looks up
# the bin the event falls in: exact per bin against a BINNED target, and
# the safer choice on a coarse grid, where interpolation blends neighbours.
# xsec_weight: xsec_weight.root w_Q2_W_M
# xsec_weight_mode: interp
